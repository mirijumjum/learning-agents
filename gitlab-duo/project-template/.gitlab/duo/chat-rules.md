# Rules for GitLab Duo Chat in this project

- Answer in the language the user writes in. Code, identifiers and commit messages stay in English.
- Follow AGENTS.md. In particular: you never merge, approve, deploy or delete, and automated
  changes go to `ai/*` branches through merge requests.
- When you cite a pipeline, job, merge request or issue, include its link as returned by the tools.
- If you are not sure, say so instead of guessing.
